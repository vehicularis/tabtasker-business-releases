# Security

## Supported versions

Security fixes go into the next release. Before you report something, check that it still happens in the
[latest Mac release](https://github.com/vehicularis/tabtasker-business-releases/releases/latest) or the latest
version in the Microsoft Store.

## Reporting a vulnerability

Please don't post it anywhere public. Tell us privately, in either of these ways:

- On GitHub: [report a vulnerability](https://github.com/vehicularis/tabtasker-business-releases/security/advisories/new)
  from the Security tab.
- By email: info@vehicularis.com

Say what you found, how to make it happen, the TabTasker Business version you saw it on (select the app in
Applications and choose File › Get Info), and your macOS or Windows version. We'll confirm we have your report,
keep you posted while we fix it, and credit you in the release notes if you'd like.

## What counts

Anything in the TabTasker Business desktop app or the releases here, for example:

- a file in a release that doesn't match its `checksums.txt`, or isn't signed by Vehicularis Limited;
- the app installing an update we didn't sign;
- a web page in the app's built-in browser, or another app, getting TabTasker Business to run commands, read
  your files, or use your camera, microphone or screen without you;
- anything in your workspace reaching someone who isn't in it.

Problems in business.tabtasker.com itself are welcome through the same two ways. A problem in a third-party
library belongs with its own project. If it affects TabTasker Business, tell us too.
